# Distance Converter (Miles ↔ Kilometers)

Проста консольна програма на Java для конвертації відстані між милями та кілометрами з підтримкою історії операцій.

## Функціонал

*   **Конвертація в обох напрямках**: 
    *   Милі в кілометри (1 mi = 1.60934 km).
    *   Кілометри в милі.
*   **Циклічне меню**: Програма працює до тих пір, поки користувач не обере вихід.
*   **Історія операцій**: Збереження результатів усіх обчислень протягом поточної сесії.
*   **Валідація введення**: Захист від некоректних даних (наприклад, введення тексту замість чисел).

## Як запустити

1.  Переконайтеся, що у вас встановлено **JDK 8** або вище.
2.  Скопіюйте код у файл з назвою `DistanceConverter.java`.
3.  Відкрийте термінал та скомпілюйте програму:
    ```bash
    javac DistanceConverter.java
    ```
4.  Запустіть програму:
    ```bash
    java DistanceConverter
    ```

## Використання

Після запуску ви побачите меню:
1. Оберіть пункт **1** або **2** для конвертації.
2. Введіть числове значення.
3. Оберіть пункт **3**, щоб переглянути всі попередні розрахунки.
4. Введіть **0**, щоб завершити роботу програми.

## Технології
*   **Java SE** (Scanner, ArrayList, String formatting).
